What to expect on first launch

When you first open the app, it starts in Demo Mode — you'll see a sample announcement along with a set of fictional volunteer and media contacts. This lets you explore every feature without touching any real data.

Demo Mode is on by default. An amber banner at the top of the screen reads "🎭 Demo Mode." When you're ready to use the app for real, tap ✕ Exit Demo on that banner. You can also toggle Demo Mode on and off anytime in the Settings tab.

Once you exit Demo Mode, add your real contacts (social media volunteers and traditional media contacts), compose an announcement, generate tailored versions for every channel with one tap, and distribute them directly from the app.

The Help tab explains each feature in detail.

How to install on your device

UUFNN Media Hub is a Progressive Web App (PWA) — it installs directly from your browser with no app store required. Once installed, it works offline; an internet connection is needed only when generating announcements.

iPhone or iPad

Safari is required on iPhone and iPad. Apple only allows Safari to install apps to your home screen. If you opened this page in Chrome, Firefox, or another app's built-in browser, the install option will not appear. Before you start, make sure you are in Safari.
  1. With UUFNN Media Hub open in Safari, tap the Share button. On newer iPhones it is inside the ⋯ menu at the bottom-right. On older iPhones it is the square-with-arrow icon in the bottom toolbar.
  2. In the share sheet, scroll the list of options down and look for Add to Home Screen (a square with a plus sign). It is often near the bottom of the list.
  3. Tap Add to Home Screen. A preview appears showing the app icon and name.
  4. Tap Add in the top-right corner to confirm.
  5. Go to your home screen and find the UUFNN Media Hub icon — a deep blue tile with a chalice and broadcast arcs.
Can't find the icon? Swipe left past your last home screen page to reach the App Library and look in "Recently Added." To move it to a home screen page, long-press the tile and tap Add to Home Screen.

Android

  1. Open UUFNN Media Hub in Chrome.
  2. If Chrome shows an Install or Add to Home Screen prompt at the bottom of the screen, tap it.
  3. If no prompt appears: tap the three-dot menu (⋮) in the top-right corner, then tap Install app or Add to Home Screen.
  4. Tap Install to confirm.
  5. The UUFNN Media Hub icon appears on your home screen. If you don't see it immediately, swipe up to open the app drawer and look there.
Two options may appear: "This app is already installed — click to open" and "Create shortcut." Choose This app is already installed for the full standalone experience without a browser bar. The shortcut option also works but keeps the browser address bar visible.

Desktop — Windows or Mac (Edge or Chrome)

Use Microsoft Edge or Google Chrome. Firefox and Safari on desktop do not support installing Progressive Web Apps. Other Chromium-based browsers (such as Vivaldi or Brave) may work but their install prompts are less reliable — Edge or Chrome are recommended for the smoothest experience.

The install button appears as a small icon at the right end of the address bar. In Edge it looks like a grid of small squares. In Chrome it looks like a monitor with a downward arrow. The screenshots below show exactly where to look and what to expect in Edge.

  1. Open UUFNN Media Hub in Edge or Chrome.
  2. Look for the install icon at the far right of the address bar — a small grid of squares in Edge, or a monitor with a downward arrow in Chrome.
  3. Click it. An install dialog appears showing the app name, icon, and publisher.
  4. Click Install to confirm.
After installing, the app appears in your Windows Start menu and can be pinned to your taskbar or desktop. To pin it: open the Start menu, find UUFNN Media Hub, right-click it, and choose Pin to taskbar or Pin to Start.
Don't see the install icon? The app may already be installed — check your Start menu or Applications folder before trying anything else. If it is already installed, the browser menu will show an "Open in app" option instead.

How to uninstall

Uninstalling removes all local data. Contacts, your announcement library, sent log, and settings are stored on your device. Use Settings → Export backup first if you want to preserve that data before uninstalling.

iPhone or iPad

  1. Long-press the UUFNN Media Hub icon on your home screen.
  2. Tap Remove App, then tap Delete App.
  3. To also clear stored browser data: open Settings → scroll to Safari → Advanced → Website Data → find abmeapps.github.io and swipe left to delete.

Android

  1. Long-press the UUFNN Media Hub icon on your home screen.
  2. Tap Uninstall, or drag the icon to the trash.
  3. To also clear stored data: open Chrome → three-dot menu → Settings → Site Settings → All Sites → find abmeapps.github.io → Clear & Reset.

Desktop (Windows or Mac)

  1. Open the installed UUFNN Media Hub app.
  2. Click the three-dot menu in the app's title bar and select Uninstall UUFNN Media Hub.
  3. Check Also clear data if prompted, then confirm.

About your data

All data — contacts, announcements, the sent log, and your library — is stored locally on your device. Nothing is sent to any server except the announcement text when you tap Generate, which is sent to an AI service to produce the tailored channel versions. No contact information is ever included in those requests.

Use Settings → Export backup to download a copy of all your data as a JSON file, and Settings → Restore to move it to a new device.
